# ISM 2411 labs — Spring 2027

Every lab is a Jupyter notebook that runs in Google Colab. Click a badge to open a lab, then immediately choose **File → Save a copy in GitHub** and save it to your `ism2411` repository at the path shown. Submit the GitHub URL of your saved notebook in Canvas.

- **Due:** Sunday at 11:59 p.m. Eastern Time of each lab's week.
- **How labs count:** no points. A lab is **Complete** when you have run every cell and honestly tried every exercise, prediction, and written answer (a ✓ on every check is not required); otherwise it is **Incomplete**.
- **Checks:** for Labs 2–13, the closed-book check on that week's material opens the next class, and one of its questions is a variant of an exercise in the lab. Lab 14 is practice for the Finance case and the portfolio.
- **Side quests:** each lab ends with an optional **★ side quest** for anyone who finishes early.

New to Colab and GitHub? Read sections 1–3 of the [technical guide](../cases/templates/TECHNICAL_GUIDE.md) first.
